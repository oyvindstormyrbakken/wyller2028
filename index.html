GitHub Pages

  • Last opp hele repo-mappen til GitHub.
  • Gå til Settings -> Pages.
  • Velg Deploy from a branch, branch main, folder /docs.
  • Åpne publisert Pages-lenke for å navigere i prosjektportalen.

Pakkeinnhold

  • docs/index.html - samlet prosjektportal.
  • docs/documents/*.html - navigerbare HTML-sider.
  • docs/documents/*.docx - Word-dokumenter.
  • docs/documents/*.xlsx - Excel-filer for styring, oppfølging og interessent-/kommunikasjonsledelse.
  • docs/documents/*.pptx - PowerPoint-rapportmal.
